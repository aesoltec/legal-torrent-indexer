# Contribuer à Legal Torrent Indexer

Merci de ton intérêt ! Ce projet est **100 % Dart/Flutter**, offline-first, et strictement limité au contenu légal (open source, domaine public, Creative Commons autorisé).

## Prérequis

- Dart SDK ≥ 3.0
- (Optionnel) Flutter pour intégrer le package dans une app

## Démarrage rapide

```bash
git clone https://github.com/aesoltec/legal-torrent-indexer.git
cd legal-torrent-indexer/dart
dart pub get
dart test
dart run example/main.dart "ISO Ubuntu 24.04"
```

## Comment contribuer

1. **Fork** le dépôt
2. Crée une branche : `git checkout -b feature/ma-amelioration`
3. Écris des tests pour tout changement du parseur
4. Respecte les règles légales du prompt (`docs/PROMPT.md` ou `dart/docs/PROMPT.md`) — aucun contournement
5. Ouvre une **Pull Request** avec une description claire

## Idées de contributions (good first issue)

- Enrichir les listes de logiciels libres / domaine public / open data
- Améliorer la détection de catégorie (multilingue)
- UI Flutter exemple (écran de recherche local)
- Documentation en anglais
- Benchmarks de performance du parseur

## Code de conduite

- Respecte le périmètre légal strict du projet
- Pas de contenu adulte, pirate ou propriétaire
- Discussions techniques bienvenues via Issues
